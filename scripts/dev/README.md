Design helpers for the vale (run from the repo root after npm run build): 'node scripts/dev/run.mjs scripts/dev/v3.mjs' opens the built game in #test mode and runs a script with helpers from lib.mjs (__top overhead, __cam, __eye, __stand); reach.mjs floods the terrain on foot from the spawn; roadcheck.mjs lists how far each road profile strays from the land; scan.mjs and profile.mjs print heights along a line and across the rim; splice.mjs replaces a block of a file between two markers. Output goes to .scratch/out (set SP to change).
